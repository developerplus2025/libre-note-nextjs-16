# Playback Speed

The app allows you to control the speed of song playback, useful for practice, learning, or creative exploration.

## Adjusting Speed

To change playback speed:

1. Open the playback speed control from the toolbar or settings panel.
2. Use the slider or input field to select a speed:
   - Range: **0.5x to 2.0x**
   - Default: **1.0x** (normal speed)

## Keyboard Shortcuts

- **Increase speed**: `Shift + >`
- **Decrease speed**: `Shift + <`
- **Reset speed**: `Shift + 0`

These shortcuts can be customized in [Settings > Keyboard Shortcuts](/settings-customization/keyboard-shortcuts).

## Use Cases

- **Practice an instrument** by slowing down complex parts.
- **Transcribe music** at a lower speed.
- **Preview tracks quickly** by increasing speed.

## Pitch Preservation

The app uses pitch-preserving playback, which means changing speed will not affect the pitch of the audio.

If pitch change is preferred (e.g., for DJ-style playback), enable **Linked Pitch Mode** in `Settings > Playback`.
