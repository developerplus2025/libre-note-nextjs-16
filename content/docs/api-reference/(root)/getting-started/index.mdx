# Getting Started

This section will help you start creating music right away.

## Launching the Application

- Use the start menu or desktop shortcut.

## Creating a New Project

1. Go to File > New Project.
2. Select a template or create an empty project.
3. Configure tempo and key.

## Adding Tracks

- Audio tracks for vocals and live instruments.
- MIDI tracks for software instruments.

## Recording and Playback

- Use the record button to capture input.
- Press play to preview your project.

## Saving Your Work

Go to File > Save and choose a location.
