# Installation

This guide walks you through installing the music software on your device, ensuring a smooth setup from start to finish.

## System Requirements

Before starting the installation, make sure your system meets the minimum requirements:

- **Operating System**: Windows 10 or later, macOS 11 or later
- **Processor**: Intel or ARM-based 64-bit processor
- **Memory**: At least 4GB RAM (8GB recommended)
- **Storage**: Minimum of 500MB free space

Higher specifications are recommended for working with large audio libraries or advanced real-time processing.

## Downloading the Installer

1. Visit the [Download Page](/download).
2. Choose the version compatible with your operating system:
   - Windows: `.exe` file
   - macOS: `.dmg` file

## Running the Installer

### On Windows

- Double-click the downloaded `.exe` file.
- If prompted by the system, allow the installer to make changes.
- Follow the on-screen instructions to complete the setup.

### On macOS

- Open the `.dmg` file.
- Drag the application into the Applications folder.
- Open the app from Launchpad or Finder. If a warning appears, go to **System Preferences > Security & Privacy** and allow the app to run.

## Launching the Application

Once installed:

- On Windows, open it from the Start Menu or desktop shortcut.
- On macOS, find it in Launchpad or the Applications folder.

The first launch may take slightly longer as the software initializes settings and resources.

## Post-Installation Setup

After launching the app:

- Confirm that the interface loads correctly.
- Go to the Settings section and check if audio output is configured properly.
- Try importing a sample song to verify playback works.
- If required, sign in using your account or create a new one to enable full functionality.

## Troubleshooting

If installation fails or the app doesn't open:

- Ensure your operating system and hardware meet the requirements.
- Temporarily disable antivirus software during installation.
- Try re-downloading the installer in case of corruption.
- For macOS, allow apps from identified developers in system preferences.

For more help, refer to the [Support Page](/support) or contact technical support.
