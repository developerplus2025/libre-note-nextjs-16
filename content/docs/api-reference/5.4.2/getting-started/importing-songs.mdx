# Importing Songs

You can import audio files from your computer into the app to build your personal library.

## Supported Formats

The app supports a wide range of audio formats, including:

- MP3
- WAV
- FLAC
- AAC
- OGG
- AIFF

Files must be valid and not DRM-protected.

## Import Methods

### Manual Import

1. Open the app.
2. Click on **Add Songs** in the sidebar or toolbar.
3. Select one or more audio files from your computer.
4. The selected files will appear in your library immediately.

### Drag and Drop

You can also drag files directly from your file explorer into the app window. The app will automatically recognize and import them.

### Folder Import

To import an entire folder:

1. Go to **Library > Import Folder**.
2. Choose the folder containing your music.
3. All supported audio files in that folder will be scanned and added.

## Auto Scan Music Folder

You can set a default music folder that the app scans on startup:

1. Open **Settings > Library**.
2. Click **Set Default Music Folder**.
3. The app will automatically check for new files in that folder each time it opens.

## File Metadata

When you import a file, the app automatically reads its metadata:

- Title
- Artist
- Album
- Genre
- Year
- Duration

You can edit this information later via the tag editor.

## Removing Files

To remove a song from your library:

1. Right-click the song.
2. Select **Remove from Library**.
3. This does not delete the actual file from your disk unless you confirm it.
