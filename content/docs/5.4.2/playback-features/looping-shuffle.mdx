# Looping & Shuffle

Loop and shuffle playback are essential tools for customizing how your music plays. These features are available in the playback control bar.

## Looping

Looping allows you to repeat songs or playlists.

### Loop Modes

There are two looping modes:

- **Repeat One** – Repeats the current song indefinitely.
- **Repeat All** – Loops the current playlist or full library from the beginning after the last track.

### How to Enable Looping

1. Locate the loop icon in the playback controls.
2. Click once to enable **Repeat All**.
3. Click again to switch to **Repeat One**.
4. Click a third time to turn looping off.

The icon will visually indicate which mode is active.

## Shuffle

Shuffle mode randomizes the order in which songs are played.

### How to Enable Shuffle

- Click the **shuffle icon** next to the loop button.
- The icon becomes active when shuffle mode is turned on.

With shuffle enabled, the app will select the next song randomly, ignoring the original playlist order.

### Queue Behavior in Shuffle Mode

When shuffle is active:

- Manual queue order is overridden.
- You can still manually select a song to play next.
- Shuffle affects the active playlist or the entire library if no playlist is selected.
