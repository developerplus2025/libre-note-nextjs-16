# Playback Features

## Play Modes
- **Normal**: Plays tracks in order
- **Shuffle**: Randomized playback
- **Repeat One / All**: Repeat current track or entire playlist

## Crossfade
Smoothly transition between songs without silence.

## Gapless Playback
Remove any pauses between tracks for a continuous experience.

## Hotkeys
- Space: Play/Pause
- → / ←: Skip forward/backward
