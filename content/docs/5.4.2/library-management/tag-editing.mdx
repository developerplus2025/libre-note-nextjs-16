# Tag Editing

Proper metadata ensures your library stays clean and searchable. You can edit tags directly within the app.

## Editable Fields

For each track, you can modify:

- Title
- Artist
- Album
- Genre
- Track Number
- Year
- Album Art (Cover)

## How to Edit Tags

1. Right-click on a song and select **Edit Tags**.
2. A popup window will show editable fields.
3. Click **Save** when done.

## Batch Editing

To edit multiple songs:

1. Select several songs.
2. Right-click > **Edit Tags**.
3. Common fields will update all selected tracks.

Useful for editing entire albums or fixing genres.

## Importing Metadata

The app supports metadata lookup from online databases (if enabled in settings). It can:

- Auto-fill missing fields
- Replace incorrect tags
- Add cover art
