# Performance Issues

Experiencing slow playback, glitches, or high CPU usage? Try the following optimizations.

## 1. Adjust Buffer Size

In **Settings** > **Audio Settings**, increase the buffer size to reduce dropouts. A higher buffer means more stable playback, but slightly more latency.

## 2. Reduce Effects and Plugins

Too many simultaneous audio effects can overload your system. Try:

- Disabling unused effects.
- Using lighter plugin alternatives.
- Freezing tracks if supported.

## 3. Close Background Apps

Other applications may consume resources. Close:

- Web browsers
- Games
- Video editors
- Cloud sync tools

## 4. Enable Performance Mode

Enable **Performance Mode** in **Settings** > **Advanced** to optimize internal processing for smoother playback.

## 5. Update Everything

Make sure your:

- Operating system
- Audio drivers
- Software version

are all up to date.
