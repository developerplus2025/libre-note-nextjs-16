# Interface Overview

Understanding the layout of the application will help you navigate it with ease and make the most out of its features.

## Main Sections

### Header Bar

Located at the top of the window, the header provides access to:

- Application logo and version
- Main navigation (Library, Effects, Settings)
- Playback status and current song
- Account options (Sign in, Profile, Settings)

### Sidebar

The left-hand sidebar allows you to:

- Switch between views: Library, Playlists, Effects
- Access saved playlists
- Browse imported or recently added tracks

### Library Panel

This is where your music is listed. It includes:

- Track name
- Artist
- Album
- Duration
- Search and sort options

You can double-click a track to start playback, or right-click for more options.

### Playback Controls

At the bottom center of the interface:

- Play, Pause, Next, Previous
- Seek bar to navigate within the track
- Volume slider
- Shuffle and loop options

### Now Playing View

When a track is playing, the current song’s information appears here:

- Album artwork
- Title, artist, album
- Elapsed and remaining time

### Effects Sidebar (optional)

If enabled in settings, a panel on the right provides quick access to:

- Equalizer
- Reverb & Delay
- Plugin chains

## Responsive Design

The interface is fully responsive and adapts to smaller screens or window resizing, hiding less-used panels and focusing on playback.
