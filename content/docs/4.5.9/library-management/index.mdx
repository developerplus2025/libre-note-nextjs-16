# Library Management

Keep your music collection organized with these tools.

## Importing Music
- Drag and drop files into the library
- Supported formats: MP3, WAV, FLAC, AAC

## Organizing
- Create playlists and folders
- Tag songs with custom metadata
- Use smart playlists for automatic sorting

## Removing Tracks
Right-click a track and select **Remove from Library**.  
This will not delete the file from your device unless you choose **Delete File**.
