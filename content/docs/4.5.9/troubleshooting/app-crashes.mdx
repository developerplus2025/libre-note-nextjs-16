# App Crashes

If the software crashes or shuts down unexpectedly, here are common causes and how to fix them.

## 1. Outdated Plugins

Third-party audio plugins can cause instability. Try launching the app in **Safe Mode** (disables all plugins) and see if it works.

## 2. Corrupt Settings

Reset the app's configuration:

- Go to `Settings` > `Advanced` > `Reset Preferences`.
- Alternatively, delete the settings file manually from the app data folder.

## 3. Software Conflicts

Disable background software such as screen recorders, antivirus, or performance boosters and test again.

## 4. Low Resources

Crashes may occur if system memory or CPU usage is too high. Try closing other apps and running a lighter project.

## Sending Crash Reports

If the app prompts to send a crash report, allow it — this helps us diagnose and resolve the issue faster.
