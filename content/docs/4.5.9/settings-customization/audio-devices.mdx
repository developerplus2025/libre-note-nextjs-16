# Audio Devices

The software allows you to select and configure the audio devices used for playback and input.

## Selecting an Output Device

1. Go to **Settings** > **Audio**.
2. Under **Output Device**, select your preferred sound card, headphones, or external speakers.
3. Click **Test Output** to confirm it's working.

## Input Device (Optional)

If you use input features (e.g. voice control or live recording):

1. Under **Input Device**, choose your microphone or audio interface.
2. Adjust input gain as needed.

## Device Refresh

If a device isn’t showing:

- Click **Refresh Devices**
- Make sure it's connected and powered on

## Advanced Settings

You can also set:

- **Buffer Size** – Useful for reducing latency
- **Sample Rate** – Default is 44.1kHz, but can be changed

These are found under **Advanced Audio Settings** in the same tab.
